# DecodeLabs

DecodeLabs is a responsive learning site introducing the foundations of building thoughtful websites.

**Live demo:** [dikshasinghthakur.github.io/project1bydecodelabs](https://dikshasinghthakur.github.io/project1bydecodelabs/)

## What This Project Covers

The page presents four practical areas of frontend development:

- **Information Architecture:** organizing content into clear, findable paths.
- **Semantic DOM:** using meaningful HTML to improve accessibility and structure.
- **CSS Layout Systems:** combining Grid and Flexbox to build adaptable layouts.
- **Asset Optimization:** using images thoughtfully while keeping pages responsive.

Visitors can filter modules by category, navigate between sections, and contact DecodeLabs by email. The layout adapts to mobile screens and uses subtle transitions and scroll reveals.

## Built With

- HTML5
- CSS3, including Grid and Flexbox
- Vanilla JavaScript
- Locally stored image assets

There is no build step or package installation required. Open index.html in a browser to view the site locally.

## Project Files

- index.html contains the page content and structure.
- style.css contains the responsive layout, visual styles, and animations.
- script.js handles navigation, module filtering, and scroll reveals.
- assets/ contains the site photography.
- .github/workflows/deploy.yml deploys the site to GitHub Pages when changes are pushed to main.
